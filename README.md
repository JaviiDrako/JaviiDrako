## 🚀 Featured Projects

### 📈 [Market Data Pipeline](https://github.com/JaviiDrako/market-data-pipeline)

End to end Data Engineering platform for cryptocurrency market data using **Python, PostgreSQL, Apache Airflow, dbt, Docker, GitHub Actions and Power BI**.

Built with a **Bronze → Silver → Gold architecture**, automated API ingestion, historical bootstrap and incremental loading, data validation, idempotent persistence, dbt transformations, technical indicators, automated testing, CI/CD and analytics ready datasets.


### 🚦 [Chicago Traffic Crashes Analytics](https://github.com/JaviiDrako/chicago-traffic-crashes-analytics-dashboard)

Cloud based analytics platform built with **Python, BigQuery, Google Cloud Storage, dbt, SQL, statistical analysis and Power BI**.

Processes more than **1 million records** through structured data layers, data quality tests, analytical transformations, statistical analysis and dimensional models designed for interactive Business Intelligence reporting.


### 🦷 [Dental Clinic ERP](https://github.com/JaviiDrako/dental-clinic-erp-pg-api)

Full stack management system built with **TypeScript, Next.js, PostgreSQL and Supabase**.

Designed to manage patients, appointments, treatments, payments and clinical operations while demonstrating database design, API integration and full stack software development.
